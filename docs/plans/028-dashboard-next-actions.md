# Plan 028 - Dashboard Next Actions

## Objective

Let the dashboard track the next buyer action for a listing.

## Scope

- Add frontend types for saved next actions.
- Let the detail panel save a next-action type, due date/time, and note.
- Preserve an existing next action when changing workflow state.

## Deferred

- Dedicated follow-up reminders or notifications.
- Filtering/sorting by next-action due date.
- Rich validation beyond the existing API contract.
