# Plan 024 - Dashboard Filter Sort

## Objective

Add lightweight local filtering and sorting to the ranked listing dashboard.

## Scope

- Filter ranked listings by workflow state.
- Sort by deal score, vehicle score, price, or mileage.
- Keep all controls local to the React dashboard.

## Deferred

- URL-backed filters.
- Server-side filtering.
- Saved dashboard views.
- More advanced facets such as seller, title, or make/model.
